# Automation Research – The Language of Automation

## 1. Bash Script

A Bash script is a file that contains a series of Linux commands that can be executed together to perform specific tasks automatically. The `#!/bin/bash` line, also called a shebang, tells the system to use the Bash interpreter when running the script.

## 2. Variables

Variables are used to store information such as folder names, file paths, and other values that a script needs. Instead of repeatedly typing the same folder path, we can assign it to a variable like `$BACKUP_DIR` and reuse it throughout the script. This makes the script easier to read and update.

## 3. Cron Job

A Cron job is a Linux scheduling feature that allows commands or scripts to run automatically at specific dates and times. It is important in cloud operations because it helps administrators automate repetitive tasks such as backups, maintenance, and system monitoring without manually executing them every time.

---

Bash scripts and Cron jobs help make cloud administration more efficient. Bash scripts automate commands, while Cron schedules those scripts to run automatically. Together, they reduce repetitive manual work and help administrators manage systems consistently.
