# CCM101 Cloud Computing Portfolio

## About Me

Hello! My name is Eric John G. Tana. I am an IT student learning about cloud computing, Linux, Git, and other cloud technologies.

## About This Repository

This repository contains my Cloud Computing laboratory activities for CCM101. It will be updated throughout the semester with my laboratory activities, documentation, screenshots, and reflections.

## Laboratory Activities

### [Laboratory 01 – Welcome to the Cloud](https://github.com/ericjohntana/CCM101-etana/tree/main/Laboratory-01-Welcome-to-the-Cloud)

This laboratory introduced the basic concepts of cloud computing and provided an overview of the cloud environment. It focused on becoming familiar with cloud computing and the tools used throughout the course.

### [Laboratory 02 – Build the Cloud Infrastructure Blueprint](https://github.com/ericjohntana/CCM101-etana/tree/main/Laboratory-02-Build-the-Cloud-Infrastructure-Blueprint)

This laboratory focused on understanding the basic infrastructure that supports cloud computing. It involved investigating a Linux server using the KillerCoda Playground, identifying compute, storage, networking, and operating system resources, comparing the infrastructure services of AWS, Microsoft Azure, and Google Cloud Platform, and creating a simple cloud infrastructure diagram.
