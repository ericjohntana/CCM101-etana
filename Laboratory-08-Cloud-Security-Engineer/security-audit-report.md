# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means that users and applications should only receive the permissions they need to perform their tasks. This is important in cloud computing because it prevents unauthorized access to important resources and reduces the risk of security breaches.

## 2. Attack Surface

An attack surface refers to all the possible entry points that attackers can use to access or compromise a virtual machine. These include open network ports, running services, applications, and user accounts. Reducing unnecessary entry points helps improve server security.

## 3. Default Deny Policy

A Default Deny Policy means that all incoming network traffic is blocked unless it is specifically allowed by the firewall. This is safer because only trusted and necessary connections can access the server instead of allowing everything and trying to block attackers individually.

These three security principles help protect cloud servers from unauthorized access. By limiting permissions, reducing unnecessary services, and blocking unwanted network traffic, administrators can create a more secure server environment.
