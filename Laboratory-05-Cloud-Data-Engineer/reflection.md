# The Cloud Data Engineer — Reflection

## My Learning Experience

Object Storage is suitable for storing millions of photos because it can handle large amounts of unstructured data and organize files as objects inside buckets. Unlike traditional block storage, which stores data in blocks, Object Storage provides a practical way to manage and access large collections of images.

Using Docker made deploying MinIO easier because I could start the server using a single command. I did not need to install and configure every component manually. Docker also allowed me to set the login credentials and ports when creating the container.

A bucket is a container used to organize and store objects in a cloud storage system. In this activity, the required bucket name is `client-photos`, which is intended to store sample images or other uploaded files.

Large enterprise companies can protect their object storage data by maintaining backups, using data replication, and storing copies across multiple servers or locations. These methods help reduce the risk of losing important files when a physical server crashes.

My confidence in using the Linux command line is gradually improving through this activity. I learned how to check the Docker version, run a container, and verify its status using terminal commands. I also experienced errors during deployment, which taught me the importance of checking command syntax and reading error messages carefully.

Overall, this activity helped me understand the basic process of deploying an object storage server using Docker. It also improved my knowledge of cloud storage and my ability to follow technical instructions. I still need more practice, especially in troubleshooting errors and verifying that the storage service works correctly, but I am becoming more comfortable using the Linux terminal.
