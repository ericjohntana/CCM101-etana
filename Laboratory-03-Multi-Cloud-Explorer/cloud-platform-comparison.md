# Cloud Platform Comparison

| ------------------- | --------------------------------------------------- | ------------------------------------ | -------------------------------------------------------- |
| Launch Year         | 2006                                                | 2010                                 | 2008                                                     |

## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is a strong choice for the broadest range of cloud services. It provides services across computing, storage, databases, networking, security, analytics, artificial intelligence, and many other categories.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations that already use Microsoft technologies. Azure integrates closely with technologies such as Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for organizations focused on artificial intelligence, machine learning, data, and Kubernetes. Google Kubernetes Engine provides managed Kubernetes capabilities, while Google Cloud also provides AI and machine learning infrastructure and services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud because of its strong combination of artificial intelligence, data analytics, and Kubernetes capabilities. These technologies are useful for modern applications and can support organizations that want to build scalable and intelligent systems.
