# AWS Research

## Amazon Web Services (AWS)

### 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. AWS provides a large collection of cloud services that organizations can use for computing, storage, databases, networking, security, analytics, artificial intelligence, and application development.

AWS was launched in 2006 and has become one of the major public cloud platforms used by startups, enterprises, government organizations, and other institutions.

### 2. Global Infrastructure

AWS operates a global cloud infrastructure organized into geographic Regions and Availability Zones. AWS Regions are separate geographic locations, while Availability Zones are isolated locations within a Region that help organizations design highly available applications.

AWS also provides additional infrastructure options such as Local Zones and other edge-related infrastructure for workloads that need lower latency or specialized deployment locations.

When selecting an AWS Region, organizations should consider factors such as latency, service availability, data residency, compliance requirements, and cost.

### 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services.

Through the console, users can create and manage resources such as virtual machines, storage buckets, databases, networks, users, and monitoring resources.

### 4. Four Core AWS Services

#### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable computing capacity in the AWS cloud. It allows organizations to run virtual machines and applications without purchasing physical servers.

#### Amazon S3

Amazon Simple Storage Service (S3) is an object storage service. It can be used to store files, images, backups, application data, and other objects.

#### Amazon RDS

Amazon Relational Database Service (RDS) is a managed relational database service that helps organizations deploy and operate relational databases.

#### AWS IAM

AWS Identity and Access Management (IAM) allows organizations to control access to AWS resources. Administrators can create users, roles, policies, and permissions.

### 5. Three Advantages of AWS

1. **Large Service Selection**
   AWS provides a broad range of cloud services covering computing, storage, databases, networking, security, analytics, AI, and other workloads.

2. **Global Infrastructure**
   AWS provides Regions and Availability Zones around the world, allowing organizations to deploy applications closer to users and design highly available systems.

3. **Scalability**
   AWS services allow organizations to increase or decrease resources according to workload requirements.

### 6. Typical Enterprise Use Cases

AWS can be used by enterprises for:

* Web and mobile applications
* Data storage and backup
* Database hosting
* Disaster recovery
* Machine learning and artificial intelligence
* E-commerce systems
* Enterprise application hosting
* Containerized applications
* Global applications

### 7. Summary

AWS is a flexible public cloud platform with a broad collection of services. Its extensive infrastructure and service ecosystem make it suitable for organizations with different workloads, from small applications to large enterprise systems.
