# Microsoft Azure Research

## Microsoft Azure

### 1. Brief Overview

Microsoft Azure is a public cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, databases, networking, security, artificial intelligence, analytics, application development, and enterprise workloads.

Azure is particularly useful for organizations that already use Microsoft technologies because it integrates with many Microsoft products and services.

### 2. Global Infrastructure

Azure's global infrastructure consists of regions, geographies, datacenters, and availability-related infrastructure.

Azure geographies contain one or more regions and are designed to support requirements such as data residency, compliance, reliability, and performance.

Organizations can select Azure regions based on factors such as location of users, service availability, data residency, compliance, and latency.

### 3. Cloud Management Console

The Azure Portal is the web-based management interface for Microsoft Azure.

Users can use the Azure Portal to create and manage virtual machines, storage accounts, databases, networks, identities, applications, monitoring resources, and other cloud services.

### 4. Four Core Azure Services

#### Azure Virtual Machines

Azure Virtual Machines provide scalable computing resources that allow organizations to run Windows or Linux operating systems in the cloud.

#### Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data such as documents, images, videos, backups, and application files.

#### Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud identity and access management service. It can be used to manage identities, authentication, and access to applications and resources.

#### Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL technologies. It allows organizations to use relational databases without managing all of the underlying database infrastructure themselves.

### 5. Three Advantages of Azure

1. **Microsoft Integration**
   Azure works closely with Microsoft technologies such as Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID.

2. **Global Infrastructure**
   Azure provides a large global infrastructure that allows organizations to select locations based on latency, availability, compliance, and data residency.

3. **Enterprise Features**
   Azure provides services and management capabilities designed for enterprise environments, including identity, security, governance, monitoring, and hybrid cloud scenarios.

### 6. Typical Enterprise Use Cases

Azure can be used for:

* Windows Server workloads
* Microsoft 365-related environments
* Enterprise applications
* Database hosting
* Web applications
* Virtual desktops
* Artificial intelligence
* Data analytics
* Hybrid cloud infrastructure
* Backup and disaster recovery

### 7. Summary

Microsoft Azure is a major public cloud platform with strong enterprise and Microsoft ecosystem integration. It is especially appropriate for organizations that already depend heavily on Microsoft technologies.
