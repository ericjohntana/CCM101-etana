# Mission Reflection

## Mission 3 – Become a Multi-Cloud Explorer

Completing Laboratory Activity 3 helped me understand the differences and similarities between AWS, Microsoft Azure, and Google Cloud. Before completing this activity, I mainly viewed cloud computing as a way to run applications and store data online. After researching the three providers, I learned that cloud platforms provide many different services for computing, storage, networking, databases, identity, artificial intelligence, containers, and other technologies.

The cloud platform that impressed me the most was **Google Cloud** because of its strong capabilities in artificial intelligence, machine learning, data analytics, and Kubernetes. I found these technologies interesting because they are important for many modern applications and business systems. However, I also learned that AWS and Azure have their own strengths and can be better choices depending on an organization's requirements.

AWS, Azure, and Google Cloud have many similarities. All three provide virtual machines, object storage, databases, networking, identity management, Kubernetes, monitoring, and other cloud services. They also provide global infrastructure that allows organizations to deploy applications in different geographic locations.

Business requirements strongly influence cloud platform selection. An organization needs to consider its existing technology, budget, application requirements, security needs, location, scalability, and technical skills. For example, a company that already depends heavily on Microsoft technologies may benefit from Azure, while an organization focused on AI and Kubernetes may consider Google Cloud.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The solution must match the client's actual business and technical requirements.

Finally, my GitHub Cloud Computing Portfolio improved because I learned how to organize technical research, comparison tables, recommendations, screenshots, and documentation using Markdown. This activity also helped me practice presenting technical information in a clearer and more professional way.
