# Final Reflection – CCM101 Cloud Computing

Throughout the CCM101 Cloud Computing course, I gained valuable knowledge and practical experience in cloud computing, Linux system administration, Docker, networking, security, and automation. From Laboratory 1 to Laboratory 10, I learned how cloud infrastructure works and how different technologies are used to build and manage cloud environments. Each laboratory activity helped me improve my technical skills, problem-solving abilities, and confidence as an Information Technology student.

During the laboratory activities, I learned how to use Linux commands, manage virtual machines, deploy applications using Docker and Docker Compose, configure network ports, and secure servers using UFW. I also gained experience in container management, persistent storage, monitoring system resources, and creating automated backup scripts using Bash and Cron Jobs. These activities helped me understand the importance of server security, data protection, automation, and proper system management in cloud computing.

One of the most challenging parts of the course was troubleshooting errors during the laboratory activities. I encountered problems involving Docker containers, network configurations, permissions, and automation scripts. However, these challenges helped me become more patient and develop my problem-solving skills. I learned that errors are part of the learning process and that understanding commands and configurations is important when managing cloud infrastructure. Creating my GitHub Cloud Computing Portfolio also helped me improve my documentation skills by organizing laboratory activities, writing Markdown files, adding screenshots as evidence, and explaining the purpose of each task.

The CCM101 course helped me develop important skills such as Linux system administration, Docker containerization, cloud infrastructure deployment, network security, Bash scripting, task scheduling, monitoring, and technical documentation. I also learned the importance of Infrastructure as Code, persistent storage, the Principle of Least Privilege, and automated backups in building reliable and secure cloud environments. These skills are useful for my future career in Information Technology, especially in cloud computing, DevOps, system administration, and cybersecurity.

Overall, CCM101 Cloud Computing was a meaningful and challenging learning experience for me. It helped me connect the concepts discussed in class with practical laboratory activities. I am thankful for the knowledge and skills I gained throughout the course. Although I still have many things to learn, I feel more confident in working with Linux, Docker, cloud infrastructure, and server security. As I continue my journey as a BSIT student, I will apply the knowledge I gained from this course to my future projects and professional development. This Cloud Computing Portfolio represents my learning progress, efforts, and experiences throughout the semester. I will continue improving my skills and exploring new technologies to become a competent and responsible IT professional.
