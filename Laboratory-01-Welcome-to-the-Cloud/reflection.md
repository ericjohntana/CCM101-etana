# Reflection

## What I Learned

In this laboratory activity, I learned how to access and use a cloud-based Linux environment using KillerCoda. I learned how to use basic Linux commands, create a new user, and navigate through folders and files.

I also learned how to check system information such as the Linux distribution, kernel version, CPU, memory, and disk space. I practiced creating directories and Markdown files using the Linux terminal.

Another important thing I learned was how to create and organize a GitHub repository. I learned how to upload my files, organize screenshots, and use Git commands to save and push my work to GitHub.

## My Experience

At first, using the Linux terminal was a little difficult because I was not familiar with some of the commands. After practicing, I became more comfortable using the terminal and understanding what each command does.

This laboratory helped me understand the importance of organizing and documenting technical work. I also learned that GitHub can be used as a portfolio to keep my laboratory activities and show my skills.
