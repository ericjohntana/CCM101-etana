# Laboratory 01 - Welcome to the Cloud

## Mission Overview

In this laboratory activity, I learned how to use a cloud-based Linux environment through KillerCoda. I also created a Linux user, explored the Linux system, and created a GitHub repository for my Cloud Computing portfolio.

## Objectives

- Learn how to use KillerCoda.
- Explore the Linux environment.
- Check basic system information.
- Create files and folders using Linux commands.
- Create a GitHub repository.
- Document my work using Markdown.

## Activities Performed

1. Opened the KillerCoda Linux Playground.
2. Created a new Linux user.
3. Logged in to the new user account.
4. Checked the username, working directory, and hostname.
5. Checked Linux system information.
6. Created the required folders and Markdown files.
7. Created a GitHub repository.
8. Added my laboratory files and screenshots.
9. Committed and pushed my work to GitHub.

## Linux Commands Used

- `whoami` - Shows the current username.
- `pwd` - Shows the current working directory.
- `hostname` - Shows the computer hostname.
- `ls` - Shows files and folders.
- `mkdir` - Creates a folder.
- `touch` - Creates a file.
- `cd` - Changes the current directory.
- `cat` - Displays the contents of a file.
- `git add` - Adds files for commit.
- `git commit` - Saves changes to Git.
- `git push` - Uploads changes to GitHub.

## Skills Learned

I learned how to work with a Linux terminal, create users and folders, check system information, use basic Linux commands, create Markdown files, and organize my work using GitHub.
